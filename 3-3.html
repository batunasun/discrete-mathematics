3.3. Евклидийн алгоритм ба лемм

Тооны онолд (мөн ерөнхийдөө математикт) хамгийн анхны агуу хувь нэмэр оруулагчдын нэг нь Грекийн математикч Александрийн Евклид (МЭӨ 300 оны орчим) байв. Хэдийгээр түүний алдарт Эхлэл (Elements) бүтээл нь геометрт оруулсан хувь нэмрээрээ илүү алдартай боловч тооны онолын чухал теоремуудыг мөн агуулдаг. Жишээлбэл, үүнд анхны тоо төгсгөлгүй олон байдаг тухай бидний баталгаанд (Теорем 3.6) ашигласан ухаалаг нотолгоо багтсан байдаг. Энэ хэсэгт Евклидийн Эхлэл зохиолын VII дэвтэрт орсон хоёр чухал үр дүнд анхаарлаа хандуулна. Эхнийх нь хамгийн их ерөнхий хуваагчийг олох болон бусад зүйлд тустай алгоритм юм. Хоёр дахь нь үржигдэхүүн болгон задлах тухай үр дүнгүүдэд суурь болох техникийн лемм юм.

Хамгийн их ерөнхий хуваагчийг олох Евклидийн алгоритмыг хэлэлцэхээсээ өмнө хамгийн их ерөнхий хуваагчийг илэрхийлж болох нэгэн маш ашигтай хэлбэрийг мэдэж авах хэрэгтэй. (3.5)-ын баруун гар талын хэлбэрийг \(m\) ба \(n\)-ийн шугаман комбинац (linear combination) гэж нэрлэдгийг тэмдэглэе.

ImportantТеорем 3.13: ХИЕХ-ийг шугаман комбинацаар илэрхийлэх нь

Зэрэг тэгтэй тэнцүү биш \(m\) ба \(n\) бүхэл тоонууд өгөгдсөн үед: \[\gcd(m, n) = mx + ny \tag{3.5}\] биелэх \(x\) ба \(y\) бүхэл тоонууд оршино.

Баталгаа. \(S = \{t : t = mu + nv, \text{ энд } u, v \in \mathbb{Z} \text{ ба } mu + nv > 0\}\) байг. \(m \cdot m + n \cdot n > 0\) тул \(S\) нь хоосон биш. Бүрэн эрэмбэлэгдэх зарчим ёсоор \(S\) олонлогт хамгийн бага элемент \(d\) олдоно. Иймд ямар нэгэн \(x, y \in \mathbb{Z}\) тоонуудын хувьд \(d = mx + ny\) бөгөөд \(d > 0\) байна. Бидний зорилго бол \(d = \gcd(m, n)\) гэдгийг харуулах явдал юм. Эхлээд бид \(d \mid m\) болохыг харуулъя.

Хуваах алгоритм ёсоор \(m = dq + r\) ба \(0 \le r < d\) байх \(q\) ба \(r\) бүхэл тоонууд оршино. \[r = m - dq = m - (mx + ny)q = m(1 - qx) + n(-qy)\] болохыг ажиглая. Хэрэв \(r > 0\) байсан бол \(r \in S\) болох ба \(r\) нь \(S\)-ийн хамгийн бага элемент болох \(d\)-ээс бага болно. Иймд \(r = 0\) байх ёстой. Өөрөөр хэлбэл, \(m = dq\) бөгөөд \(d \mid m\) байна. Яг үүнтэй төстэй үндэслэлээр \(d \mid n\) болохыг харуулж чадна.

Одоо \(d\) нь ерөнхий хуваагчид дотроос хамгийн их нь болохыг харуулах үлдлээ. Тиймээс \(c\) нь \(c \mid m\) ба \(c \mid n\) байх бүхэл тоо гэж үзье. Иймд ямар нэгэн \(a, b \in \mathbb{Z}\) тоонуудын хувьд \(m = ac\) ба \(n = bc\) болно. Эндээс: \[d = mx + ny = acx + bcy = (ax + by)c\] болно. Тиймээс \(c \mid d\). Теорем 3.1 ёсоор \(c \le d\) болно. Ийнхүү \(\gcd(m, n) = d = mx + ny\). \(\square\)

Теорем 3.13-ын дараах шууд мөрдөлгөөний баталгааг дасгалд үлдээсэн болно.

ImportantМөрдөлгөө 3.14

\(m\) ба \(n\) хоёр бүхэл тоо харилцан анхны байх нь \(mx + ny = 1\) биелэх \(x\) ба \(y\) бүхэл тоонууд оршихтой зайлшгүй бөгөөд хүрэлцээтэй.

Теорем 3.13 ба Мөрдөлгөө 3.14-ийн үр дүнгүүдийг дараах жишээгээр харуулав.

TipЖишээ 3.22

(а) \(\gcd(18, 30) = 6\), бөгөөд \(6 = 18(-3) + 30(2)\) болохыг ажиглая.

(б) \(14\) ба \(9\) нь харилцан анхны, бөгөөд \(14(2) + 9(-3) = 1\) болохыг ажиглая. \(\blacksquare\)

Жишээ 3.22-т үзүүлсэн шугаман комбинацуудыг шалгахад хялбар боловч тэдгээрийг хэрхэн олох вэ?

Евклидийн алгоритм (Euclid’s Algorithm)

Алгоритм гэдэг нь хүссэн үр дүнд хүргэх төгсгөлөг тооны энгийн заавруудын жагсаалт гэдгийг эргэн саная. Зөвхөн хамгийн их ерөнхий хуваагчийг төдийгүй Теорем 3.13-т амласан \(x\) ба \(y\) бүхэл тоонуудыг олох Евклидийн алгоритм хэмээх арга үнэхээр оршдог. Гэсэн хэдий ч энэ алгоритм хэрхэн ажилладгийг харахын тулд бид эхлээд хамгийн их ерөнхий хуваагчийг тооцоолоход анхаарлаа хандуулъя.

Эхлээд \(\gcd(m, n) = \gcd(|m|, |n|)\) тул \(m\) ба \(n\) хоёулаа сөрөг биш байх үед \(\gcd(m, n)\)-ийг тооцоолох аргатай байхад л хангалттай гэдгийг ажиглая. Евклидийн ашигласан шийдвэрлэх үр дүн бол Хуваах алгоритмын хэрэглээ юм.

ImportantТеорем 3.15: ХИЕХ-ийг бууруулах нь (GCD Reduction)

\(n \ge m > 0\) байх \(n\) ба \(m\) бүхэл тоонууд байг. \(0 \le r < m\) байх \(q, r \in \mathbb{Z}\) тоонуудын хувьд \(n = mq + r\) гэж бичье. Тэгвэл: \[\gcd(n, m) = \gcd(m, r).\]

Баталгаа. \(\gcd(n, m) = \gcd(m, r)\) гэдэг нь \((n, m)\) болон \((m, r)\) хосууд ижил ерөнхий хуваагчдын олонлогтой байдаг баримтын шууд мөрдөлгөө бөгөөд бид үүнийг одоо батална.

  • \((\rightarrow)\) \(c\) нь \(n\) ба \(m\)-ийн ерөнхий хуваагч гэж үзье. Өөрөөр хэлбэл, ямар нэгэн \(k\) ба \(l\) бүхэл тоонуудын хувьд \(n = ck\) ба \(m = cl\) байна. \[r = n - mq = ck - clq = c(k - lq)\] болохыг ажиглая. Иймд \(c \mid r\) бөгөөд \(c \mid m\) байна. Өөрөөр хэлбэл, \(c\) нь \(m\) ба \(r\)-ийн ерөнхий хуваагч мөн.
  • \((\leftarrow)\) \(c\) нь \(m\) ба \(r\)-ийн ерөнхий хуваагч гэж үзье. Өөрөөр хэлбэл, ямар нэгэн \(k\) ба \(l\) бүхэл тоонуудын хувьд \(m = ck\) ба \(r = cl\) байна. \[n = mq + r = ckq + cl = c(kq + l)\] болохыг ажиглая. Иймд \(c \mid n\) бөгөөд \(c \mid m\) байна. Өөрөөр хэлбэл, \(c\) нь \(n\) ба \(m\)-ийн ерөнхий хуваагч мөн. \(\square\)

Теорем 3.15-ын гол санаа нь \((n, m)\) хосын ХИЕХ-ийг тооцоолох бодлогыг илүү бага \((m, r)\) хосын ХИЕХ-ийг тооцоолох бодлогоор солих боломжийг олгодогт оршино. Ийм бууруулалтын дарааллаар бид ерөнхий бодлогыг шийдэхэд хялбар хамаагүй жижиг бодлого руу шилжүүлж чадна. Тухайлбал, эдгээр бууруулалт нь эцэстээ бүхэл тоонуудын аль нэг нь \(0\) байх хос руу хүргэнэ. Тэр цэг дээр Жишээ 3.8-ийн үр дүн тооцооллыг дуусгана: \[\text{Хэрэв } k \text{ нь эерэг бүхэл тоо бол } \gcd(k, 0) = k.\] Бид Евклидийн алгоритмыг хэд хэдэн жишээн дээр харуулъя.

TipЖишээ 3.23

\(\gcd(48, 18)\)-ийг тооцоол.

Бодолт. Бид Теорем 3.15-ыг давтан хэрэглэнэ: \[ \begin{aligned} \gcd(48, 18) &= \gcd(18, 12) && \text{учир нь } 48 = (18)2 + 12 \\ &= \gcd(12, 6) && \text{учир нь } 18 = (12)1 + 6 \\ &= \gcd(6, 0) && \text{учир нь } 12 = (6)2 + 0 \\ &= 6 && \text{Жишээ 3.8 ёсоор.} \quad \blacksquare \end{aligned} \]

Евклидийн алгоритмын үндсэн процедурыг Алгоритм 3.1-д харуулав. Францын математикч Габриэль Ламе (1795–1870) \(n \ge m > 0\) үед \(\gcd(n, m)\)-ийг тооцоолоход хамгийн ихдээ \(5m\) алхам (энд \(m\) нь оронгийн тоо) шаардагдана гэдгийг баталжээ. Евклидийн алгоритмын өөр нэг мөрдөлгөө нь \(\gcd(n, m)\)-ийг \(n\) ба \(m\)-ийн шугаман комбинац хэлбэрээр бичих бүхэл коэффициентүүдийг олох боломжийг олгодог бөгөөд үүнийг дараах хоёр жишээгээр харуулъя.

NoteАлгоритм 3.1: \(\gcd(n, m)\)-ийг олох Евклидийн алгоритм

\(n, m \in \mathbb{Z}^+\) ба \(n \ge m\) байг.

Алгоритм.

While m > 0:
    r = n mod m болгоно.
    n = m болгоно.
    m = r болгоно.
n-ийг буцаана.
TipЖишээ 3.24

\(\gcd(630, 96)\)-г олж, түүнийг \(x, y \in \mathbb{Z}\) байх \(630x + 96y\) хэлбэрээр бич.

Бодолт. Эхний алхмууд нь Жишээ 3.23-т ашигласантай ижил байна:

\[\begin{aligned} \gcd(630, 96) &= \gcd(96, 54) && \text{учир нь } 630 = (96)6 + 54 \\ &= \gcd(54, 42) && \text{учир нь } 96 = (54)1 + 42 \\ &= \gcd(42, 12) && \text{учир нь } 54 = (42)1 + 12 \\ &= \gcd(12, 6) && \text{учир нь } 42 = (12)3 + 6 \\ &= \gcd(6, 0) && \text{учир нь } 12 = (6)2 + 0 \\ &= 6 && \text{Жишээ 3.8 ёсоор.} \end{aligned}\]

Нэмэлт багахан үйлдэл хийснээр эдгээр тооцооллыг \(x\) ба \(y\)-ийг олоход ашиглаж болно. Хамгийн их ерөнхий хуваагч болох \(6\) нь бидний тооцоололд гарсан хамгийн сүүлийн тэг биш үлдэгдэл гэдгийг анхаарна уу. Тэрхүү сүүлийн тэг биш үлдэгдэл хүртэл бидэнд дараах тэгшитгэлүүд байна:

\[\begin{aligned} 54 &= 630 - (96)6 \\ 42 &= 96 - (54)1 \\ 12 &= 54 - (42)1 \\ 6 &= 42 - (12)3. \end{aligned}\] Хамгийн сүүлийн мөрөөс эхлэн ухрааж орлуулбал бид дараахыг гаргаж авна: \[ \begin{aligned} 6 &= 42 - (12)3 \\ &= 42 - (54 - 1(42))3 = (54)(-3) + (42)(4) \\ &= (54)(-3) + (96 - 1(54))(4) = (96)(4) + (54)(-7) \\ &= (96)(4) + (630 - 6(96))(-7) = (630)(-7) + (96)(46). \end{aligned} \] Өөрөөр хэлбэл, \(x = -7\) ба \(y = 46\) үед \(\gcd(630, 96) = 6 = 630x + 96y\) болно. \(\blacksquare\)

TipЖишээ 3.25

\(\gcd(102, 30)\)-ийг олж, түүнийг \(x, y \in \mathbb{Z}\) байх \(102x + 30y\) хэлбэрээр бич.

Бодолт. \[ \begin{aligned} \gcd(102, 30) &= \gcd(30, 12) && \text{учир нь } 102 = (30)3 + 12, && \text{тиймээс } 12 = 102 - (30)3 \\ &= \gcd(12, 6) && \text{учир нь } 30 = (12)2 + 6, && \text{тиймээс } 6 = 30 - (12)2 \\ &= \gcd(6, 0) && \text{учир нь } 12 = (6)2 + 0 \\ &= 6 && \text{Жишээ 3.8 ёсоор.} \end{aligned} \] Иймд: \[6 = 30 - (12)2 = 30 - (102 - 3(30))2 = (102)(-2) + (30)(7).\] Өөрөөр хэлбэл, \(x = -2\) ба \(y = 7\) үед \(\gcd(102, 30) = 6 = 102x + 30y\) болно. \(\blacksquare\)

Жишээ 3.24 ба 3.25-д \(d = \gcd(m, n) = mx + ny\) байх \(d, x\), ба \(y\)-ийг олоход ашигласан процедурыг Өргөтгөсөн Евклидийн алгоритм (Extended Euclidean Algorithm) гэж нэрлэдэг. Mathematica болон Maple программуудад энэ даалгаврыг гүйцэтгэхэд зориулсан харгалзан ExtendedGCD болон igcdex функцүүд байдаг.

Үржигдэхүүн болгон задлах тухай леммүүд

Бид энэ хэсгийг дараагийн хэсгүүдэд шаардагдах үржигдэхүүн болгон задлах тухай зарим чухал үр дүнгүүдээр өндөрлөе. Эдгээр нь бүгд Евклидийн лемм хэмээх суурь үр дүнгээс эхтэй. Нийтлэг агуулга нь бүхэл тоо аливаа үржвэрийг хуваадаг бол уг бүхэл тоо тэр үржвэрийн аль нэг үржигдэхүүнийг хуваах нөхцөлийг тодорхойлох явдал юм. Жишээлбэл, \(6 \mid (9 \cdot 10)\) боловч \(6 \nmid 9\) ба \(6 \nmid 10\) байхад, \(5 \mid (9 \cdot 10)\) бөгөөд хэдийгээр \(5 \nmid 9\) боловч \(5 \mid 10\) гэдэг нь үнэн юм.

ImportantТеорем 3.16: Евклидийн лемм (Euclid’s Lemma)

\(m, n\), ба \(c\) нь бүхэл тоонууд байг. Хэрэв \(c \mid mn\) ба \(\gcd(c, m) = 1\) бол \(c \mid n\) байна.

Баталгаа. \(c \mid mn\) ба \(\gcd(c, m) = 1\) гэж үзье. Тэгвэл ямар нэгэн \(k \in \mathbb{Z}\) тооны хувьд \(mn = ck\) болно. Мөрдөлгөө 3.14 ёсоор \(cx + my = 1\) биелэх \(x, y \in \mathbb{Z}\) тоонууд оршино. \[n = (cx + my)n = cnx + mny = cnx + cky = c(nx + ky)\] болохыг ажиглая. Тиймээс \(c \mid n\). \(\square\)

ImportantМөрдөлгөө 3.17

\(m, n\), ба \(p\) нь бүхэл тоонууд бөгөөд \(p\) нь анхны тоо байг. Хэрэв \(p \mid mn\) бол \(p \mid m\) эсвэл \(p \mid n\) байна.

Мөрдөлгөө 3.17-ийн баталгааг дасгалд үлдээв. Дараагийн мөрдөлгөө нь индукцийн аргаар батлахад аяндаа зохицдог. 4.3-р хэсэгт индукцийг танилцуулсны дараа тэрхүү дасгалуудад баталгааг нь хийхийг шаардах болно.

ImportantМөрдөлгөө 3.18

\(m_1, m_2, \dots, m_n\), ба \(p\) нь бүхэл тоонууд бөгөөд \(p\) нь анхны тоо байг. Хэрэв \(p \mid (m_1 \cdot m_2 \cdots m_n)\) бол ямар нэгэн \(1 \le i \le n\)-ийн хувьд \(p \mid m_i\) байна.

ImportantМөрдөлгөө 3.19

\(m, n\), ба \(p\) нь бүхэл тоонууд бөгөөд \(n > 0\) ба \(p\) нь анхны тоо байг. Хэрэв \(p \mid m^n\) бол \(p \mid m\) байна.

Бид сүүлийн жишээнийхээ баталгаанд Мөрдөлгөө 3.19-ийг хэрэглэнэ. Өөр нэгэн баталгааг 4.5-р хэсгийн дасгалуудад тоймлон харуулсан болно.

TipЖишээ 3.26

\(a, b\), ба \(n\) нь бүхэл тоонууд бөгөөд \(n > 0\) байг. Хэрэв \(\gcd(a, b) = 1\) бол \(\gcd(a, b^n) = 1\) болохыг харуул.

Баталгаа. \(\gcd(a, b) = 1\) гэж үзье. \(d = \gcd(a, b^n)\) гэе. Зөрчилд хүрэхийн тулд эсрэгээс нь \(d > 1\) гэж үзье. Теорем 3.5 ёсоор бидэнд \(p \mid d\) байх анхны \(p\) тоо олдоно. Тиймээс \(p \mid a\) ба \(p \mid b^n\) болно. Мөрдөлгөө 3.19 ёсоор \(p \mid b\) болно. Иймд \(p \mid \gcd(a, b)\) болж байна. Өөрөөр хэлбэл \(p \mid 1\) болох бөгөөд \(p\) нь анхны тоо тул энэ нь боломжгүй юм. Иймд \(d = 1\). \(\blacksquare\)

Гэсэн хэдий ч \(a\) ба \(b\)-ийг зэрэг тэгтэй тэнцүү биш бүхэл тоонууд, \(m\) ба \(n\)-ийг эерэг бүхэл тоонууд гэвэл \(\gcd(a, b)\) ба \(\gcd(a^m, b^n)\) нь ижил анхны хуваагчидтай болохыг харуул.
  24. \(\star\) \(2^4 \mid (40 \cdot 6)\) боловч \(2^4 \nmid 40\) ба \(2^4 \nmid 6\) хэдий ч бидэнд \(2^3 \mid 40\) ба \(2^1 \mid 6\) (\(2^3 2^1 = 2^4\) гэдгийг тэмдэглэе) байгааг ажиглая. Ерөнхий тохиолдолд, \(m, n, p, k \in \mathbb{Z}\) ба \(p\) анхны тоо, \(k \ge 0\) байг. \(p^k \mid mn\) гэж үзье. \(a + b = k\), \(p^a \mid m\), ба \(p^b \mid n\) байх \(a, b \in \mathbb{N}\) оршино гэдгийг харуул. Зөвлөмж: 3.2-р хэсгийн Дасгал 28-ыг ашиглан \(p^a \mid m\) байхаар \(a\)-г аль болох ихээр сонго. \(p^{k-a} \mid \left(\frac{m}{p^a} n\right)\) баримтад Евклидийн леммийг хэрэглэ.

31-ээс 33 хүртэлх дасгалуудын өгүүлбэрүүдийг батлахдаа Дасгал 30 дахь баримтыг ашигла.

  1. Зэрэг тэгтэй тэнцүү биш бүх \(m, n \in \mathbb{Z}\) хувьд \(\gcd(m, n) = \gcd(n, m)\) болохыг харуул.
  2. Зэрэг тэгтэй тэнцүү биш бүх \(m, n \in \mathbb{Z}\) хувьд \(\gcd(m, -n) = \gcd(m, n)\) болохыг харуул.
  3. Бүх \(k \in \mathbb{Z}^+\) хувьд \(\gcd(k, 0) = k\) болохыг харуул.
  4. Теорем 3.15-ыг батал.
  5. \(m, n \in \mathbb{Z}^+\) өгөгдсөн үед Теорем 3.13-ыг ашиглан: \(\forall c \in \mathbb{Z}\), хэрэв \(c \mid m\) ба \(c \mid n\) бол \(c \mid \gcd(m, n)\) болохыг харуул.
  6. \(d = \gcd(m, n)\) байг. \(m = ad\) ба \(n = bd\) байх \(\gcd(a, b) = 1\) нөхцөлийг хангах \(\exists a, b \in \mathbb{Z}\) оршино гэдгийг харуул.
  7. Дурын бүхэл \(n\) тооны хувьд \(5n + 3\) ба \(7n + 4\) бүхэл тоонууд харилцан анхны болохыг харуул.
  8. Дурын бүхэл \(n\) тооны хувьд \(5 - 2n\) ба \(n - 3\) бүхэл тоонууд харилцан анхны болохыг харуул.
