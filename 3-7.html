3-р бүлгийн тойм бодлогууд

  1. Аливаа хоёр тэгш бүхэл тооны үржвэр тэгш болохыг харуул.

  2. \(\forall n \in \mathbb{Z}\) хувьд хэрэв \(4 \nmid n^2\) бол \(n\) сондгой болохыг харуул.

  3. Бридж хөзрийн тоглоомонд стандарт багцын бүх \(52\) хөзрийг дөрвөн тоглогчид тус бүр ижил тооны хөзөр авахаар хувааж өгдөг. Бид бриджтэй төстэй боловч зургаан тоглогчид зориулсан тоглоом зохиохыг хүсэж байна гэе. \(52\) хөзөртэй багцыг зургаан тоглогчид тэнцүү хувааж болох уу? Яагаад?

  4. \(a, b \in \mathbb{Z}\) байг. \(a \mid ((a + b)^3 - b^3)\) болохыг харуул.

  5. \(a, b \in \mathbb{Z}\) байг. \(a \mid b\) байх нь \(-a \mid b\) байхтай зайлшгүй бөгөөд хүрэлцээтэй болохыг харуул.

  6. \(91\) анхны тоо мөн үү? Яагаад? \(1\) анхны тоо мөн үү? Яагаад?

  7. \(14\) ба \(33\) нь харилцан анхны тоонууд мөн үү? Яагаад?

  8. \(a\) ба \(n\) нь бүхэл тоонууд байг. Хэрэв \(a \mid n\) ба \(a \mid (n + 2)\) бол \(a \mid 2\) болохыг харуул.

  9. Үржигдэхүүн болгон задлах замаар \(\gcd(1001, 455)\)-ийг ол.

  10. \(n \in \mathbb{Z}\) ба \(n \neq 0\) байг. \(\gcd(n, -n) = |n|\) болохыг харуул. Энд \[|n| = \begin{cases} n & \text{хэрэв } n \ge 0, \\ -n & \text{хэрэв } n < 0 \end{cases}\] болохыг тэмдэглэе.

  11. \(a\) ба \(b\)-ийг зэрэг тэгтэй тэнцүү биш бүхэл тоонууд, \(m\) ба \(n\)-ийг эерэг бүхэл тоонууд гэе. (а) \(m, n > 1\) ба \(\gcd(a, b) = \gcd(a^m, b^n)\) байх \(a, b, m, n\)-ийн тодорхой утгуудыг ол. (б) Ерөнхий тохиолдолд, \(\gcd(a, b) \le \gcd(a^m, b^n)\) болохыг харуул. (в) \(\star\) \(\gcd(a, b) < \gcd(a^m, b^n)\) гэсэн эрс тэнцэтгэл биш биелэхийн тулд \(a, b, m, n\) дээр ямар нэмэлт нөхцөлүүд тавигдах вэ?

  12. \(\operatorname{lcm}(120, 84)\)-ийг ол.

  13. \(\operatorname{lcm}(6^9, 6^{15}) = 6^{15}\) болохыг ажиглая. \(m > 0\) байх \(\forall m, j, k \in \mathbb{N}\) хувьд \(\operatorname{lcm}(m^j, m^k) = m^{\max\{j, k\}}\) болохыг харуул.

  14. \(\{s : s = 10x + 25y, \text{ энд } x, y \in \mathbb{Z} \text{ ба } 10x + 25y > 0\}\) олонлогийн хамгийн бага элементийг ол.

  15. Мерсенний анхны тоо гэдэг нь ямар нэгэн анхны \(p\) тооны хувьд \(2^p - 1\) хэлбэртэй анхны тоог хэлдгийг эргэн саная. Дараах өгүүлбэр үнэн эсвэл худал болохыг шийд: \(113\) нь анхны тоо тул \(2^{113} - 1\) мөн анхны тоо байна. Зөвлөмж: GIMPS веб сайтыг үзнэ үү.

  16. \(101 \div 8\) бүхэл тоог хуваах бодлогын ногдвор ба үлдэгдлийг ол.

  17. Тооцоол: (а) \(43 \operatorname{div} 7\) ба \(43 \bmod 7\). \(\qquad\) (б) \(-51 \operatorname{div} 9\) ба \(-51 \bmod 9\).

  18. Стандарт хөзрийн хоёр багцыг (тус бүр \(52\) хөзөртэй) хооронд нь хольж, \(6\) тоглогчид дараах байдлаар хувааж өгсөн гэе. Хуваалтын тойрог бүрд хэрэв овоолгод хамгийн багадаа \(6\) хөзөр үлдсэн байвал тоглогч бүрд нэг хөзөр нэмж өгнө. \(6\)-аас цөөн хөзөр үлдэх үед хуваалт зогсоно. Хуваалт зогсоход хэдэн хөзөр үлдэх вэ? Тоглогч бүр хэдэн хөзөртэй болох вэ? Дасгал 3-тай харьцуул.

  19. \(\forall n \in \mathbb{Z}\) хувьд \((n^3 - n) \bmod 3 = 0\) болохыг харуул.

  20. \(n \in \mathbb{Z}\) байг. Хэрэв \(n\) сондгой бол \(4 \nmid n^2\) болохыг харуул. Энэ нь Дасгал 2-ын урвуу өгүүлбэр болохыг тэмдэглэе.

  21. Ол: (а) \(\lfloor 6.6 \rfloor\). \(\quad\) (б) \(\lfloor -6.6 \rfloor\). \(\quad\) (в) \(\lceil 5.4 \rceil\). \(\quad\) (г) \(\lceil -5.4 \rceil\).

  22. \(\forall n \in \mathbb{Z}\) хувьд хэрэв \(4 \mid n\) бол \(\left\lfloor \frac{n + 2}{4} \right\rfloor = \frac{n}{4}\) болохыг харуул.

  23. \(\forall x \in \mathbb{R}\) хувьд \(\lceil \lceil x \rceil \rceil = \lceil x \rceil\) болохыг харуул.

  24. Хуучин эд зүйлсийн худалдаанаас авсан номын ISBN дугаарын нэг цифр баларч арилжээ. Хэрэв ISBN нь 0-8218-#461-4 бол баларсан # цифрийн утга хэд вэ? Хэрэв хоёр цифр баларсан байсан бол үлдсэн цифрүүдээр тэдгээрийг тодорхойлж чадах байсан уу?

  25. Ахлах сургуулийн хоёр охин " " = 0, A = 1, ..., Z = 26 үсэг-тооны хөрвүүлэлт болон \(n = 27\), шифрлэх шилжүүлгийн утга \(b = 4\) бүхий шилжүүлэх шифр ашиглан нууц мессеж илгээхээр тохиролцжээ. Ингэснээр багш нь мессежийг барьж авсан ч уншиж чадахгүй юм. Охидын нэг нь "I LOVE TOM" мессежийг хэрхэн шифрлэх вэ?

  26. \(\star\) Өгөгдсөн \(n\) ба \(b\)-ийн хувьд шилжүүлэх шифр нь дараах мөчлөгүүдийг агуулна: \[x_1 \rightarrow x_2 \rightarrow \dots \rightarrow x_k \rightarrow x_1 \quad (\text{шифрлэгдэнэ}).\] Жишээлбэл, \(n = 27\) (" " = 0, A = 1, ..., Z = 26 үсэг-тооны хөрвүүлэлттэй) ба \(b = 6\) үед бидэнд: \[A \rightarrow G \rightarrow M \rightarrow S \rightarrow Y \rightarrow D \rightarrow J \rightarrow P \rightarrow V \rightarrow A\] гэсэн \(9\) урттай мөчлөг үүснэ. Ерөнхий тохиолдолд, \(n\) ба \(b\)-ээр илэрхийлбэл эдгээр мөчлөгийн урт \(k\) хэд байх вэ? Төрөл бүрийн жишээ туршиж, зүй тогтлыг нээн илрүүл.

  27. Турших ба алдаа гаргах (сонгон шалгах) аргаар \(35x + 49y = 7\) байх \(x, y \in \mathbb{Z}\) тоонуудыг ол.

  28. \(85x + 39y = 1\) байх \(\exists x, y \in \mathbb{Z}\) өгүүлбэрийг батал эсвэл няцаа.

  29. Евклидийн алгоритмыг ашиглан \(\gcd(110, 88)\)-ийг ол.

  30. Евклидийн алгоритмыг ашиглан \(\gcd(810, 245)\)-ийг ол.

  31. Өргөтгөсөн Евклидийн алгоритмыг ашиглан \(\gcd(81, 45) = 81x + 45y\) байх \(x\) ба \(y\) бүхэл тоонуудыг ол.

  32. Өргөтгөсөн Евклидийн алгоритмыг ашиглан \(77x + 24y = 1\) байх \(x\) ба \(y\) бүхэл тоонуудыг ол.

  33. \(5 \mid 4^3 10^2\) бөгөөд тухайлбал \(5 \mid 10\) болохыг ажиглая. \(m, n > 0\) байх \(a, b, m, n \in \mathbb{Z}\) байг. Хэрэв \(5 \mid a^m b^n\) бол \(5 \mid a\) эсвэл \(5 \mid b\) болохыг харуул.

  34. Дасгал 3 ба 18-д бид хөзрийн багцуудыг зургаан тоглогчид хуваах тухай авч үзсэн. \(n\) багц хөзөр зургаан тоглогчид тэнцүү хуваагдах нь \(n\) нь \(3\)-т хуваагдахтай зайлшгүй бөгөөд хүрэлцээтэй болохыг харуул.

  35. \(a, b \in \mathbb{Z}\) байг. Хэрэв \(10 \mid ab\) бол \(10 \mid a\) эсвэл \(10 \mid b\) гэдэг нь үнэн үү? Хариултаа үндэслэ.

  36. Та бүх зүйлийн төлбөрийг зөвхөн \(25\) цент (quarter) болон \(10\) центийн (dime) зоосоор төлөхийг хүсэж байна гэе. (а) Энэ аргаар бүрдүүлэх боломжгүй мөнгөн дүнгүүд (доллар ба цент) төгсгөлгүй олон байна гэдгийг харуул. (б) \(5\) центийн ямар хуваагдагчдыг энэ аргаар бүрдүүлэх боломжгүй вэ? (в) Хэрэв бидэнд мөн \(2\) центийн үнэтэй зооснууд байсан бол ямар утгуудыг бүрдүүлж чадахгүй байх вэ?

  37. \(6\frac{3}{4}\) нь рационал болохыг харуул.

  38. \(1.\overline{414}\) нь рационал болохыг харуул. Энэ тоо \(\sqrt{2}\)-оос их үү эсвэл бага уу? Тооны машин ашиглахгүйгээр хариултаа батал.

  39. \(1.6\overline{25}\) нь рационал болохыг харуул.

  40. \(\forall r \in \mathbb{R}\) хувьд хэрэв \(r \in \mathbb{Q}\) бол \(\frac{3r}{4} \in \mathbb{Q}\) болохыг харуул.

  41. \(r \in \mathbb{Q}\) байг. \(r^2\) нь рационал болохыг харуул.

  42. \(\frac{14}{15}\) ба \(\left(\frac{14}{15}\right)^2 = \frac{196}{225}\) нь хоёулаа үл хураагдах хэлбэрт байгааг ажиглая. \(r = \frac{a}{b}\) нь үл хураагдах хэлбэрээр бичигдсэн рационал тоо гэе. \(r^2 = \frac{a^2}{b^2}\) мөн үл хураагдах хэлбэрт байна гэдгийг харуул.

  43. Тооны машин ашиглахгүйгээр \(\frac{5}{11}\)-ийг аравтын хэлбэрээр бич. Бодолтоо харуул.

  44. \(\sqrt{2}\)-ийг иррационал болохыг баталсан баталгааг дуурайн \(\sqrt{7}\)-г иррационал болохыг харуул.

  45. Дасгал 44-ийн үр дүнг ашиглан \(\frac{5 + \sqrt{7}}{3}\)-ийг иррационал болохыг харуул.

  46. \(\log_3 11\) нь иррационал болохыг харуул.

  47. 1737 онд Эйлер \(e\) ба \(e^2\)-ийг иррационал болохыг баталжээ. 1768 онд Ламберт \(e\)-ийн тэгээс ялгаатай бүх бүхэл зэргүүд иррационал болохыг баталсан. \(e\)-ийн тэгээс ялгаатай бүхэл зэрэг бүр иррационал гэж өгөгдсөн үед дараахыг гүйцэтгэ: (а) \(\frac{e^2 - 4}{3}\) нь иррационал болохыг харуул. (б) \(\ln 2\) нь иррационал болохыг харуул. Энд \(\ln 2\)-ийг \(\log_e 2\) гэж тодорхойлдгийг тэмдэглэе.

  48. \(\sqrt{3} + \sqrt{2}\) нь иррационал болохыг харуул.

  49. \(\frac{\sqrt[3]{2}}{\sqrt{5}}\) нь иррационал болохыг харуул.

  50. \(\theta = 11.25^\circ\) үед \((2\cos^2(\theta) - 1)^2 = \cos^2(2\theta) = \frac{1 + \cos(4\theta)}{2}\) тригонометрийн адилтгалыг ашиглавал бид \(\cos(11.25^\circ) = \frac{1}{2}\sqrt{2 + \sqrt{2 + \sqrt{2}}}\) болохыг ажиглана. Үүнийг ашиглан \(\cos(11.25^\circ)\)-ийг иррационал болохыг батал.

  51. \(\frac{5}{4}x^2 - \frac{2}{3}x + 1\) олон гишүүнтийн язгуурууд алгебрлаг уу? Яагаад?

  52. 2004 оны 2-р сарын 1-нд New England Patriots баг Super Bowl XXXVIII-д түрүүлсэн. Мөн тэр жилдээ 10-р сарын 27-нд Boston Red Sox баг World Series-т түрүүлж, Бамбиногийн хараалыг эцэслэжээ. Super Bowl Ням гарагт болсон тул Red Sox баг 2004 оны World Series-т долоо хоногийн аль гарагт түрүүлснийг тодорхойл.

  53. \(n > 1\) байх \(a, b, c\), ба \(n\) бүхэл тоонууд байг. Хэрэв \(a \equiv b \pmod n\) бол \(ac \equiv bc \pmod n\) болохыг харуул.

  54. Тооцоол: (а) \(11^{10} \bmod 9\). \(\qquad\) (б) \(23^{4321} \bmod{12}\).

  55. \(n \in \mathbb{Z}\) байг. Хэрэв \(n\) сондгой бол \(n^2 \equiv 1 \pmod 4\) болохыг харуул.

  56. \(n \in \mathbb{Z}\) байг. Хэрэв \(n \not\equiv 0 \pmod 3\) бол \(n^2 \equiv 1 \pmod 3\) болохыг харуул.

  57. Өндөр нууцлалтай бүсэд нэвтрэхийн тулд ТТГ-ын (CIA) ажилтанд цоожинд оруулах гурван тэмдэгттэй код шаардлагатай. Энэ кодыг нууцлах ёстой тул ажилтанд илгээхийн өмнө " " = 0, A = 1, ..., Z = 26 үсэг-тооны хөрвүүлэлт болон \(n = 27\), \(a = 4\), \(b = 1\) бүхий шугаман шифр ашиглан кодыг шифрлэжээ. Хэрэв нууцлагдсан код нь "SWE" бол ямар код цоожийг нээх вэ?

  58. Өргөтгөсөн Евклидийн алгоритмыг ашиглан \(50\) модулиар авсан \(11\)-ийн үржвэрийн урвууг ол.

  59. Хээрийн бүх ТТГ-ын ажилтнууд \(p = 7, q = 13\), ба \(a = 17\) бүхий RSA шифрлэлтийн аргыг ашиглан төв штаб руугаа мессеж илгээдэг. Зарим стандарт мессежийн тоон эквивалентуудыг Хүснэгт 3.7-д харуулав.

    Мессежийн нууцлалыг тайлахад шаардлагатай \(c = 5\) утгыг зөвхөн ТТГ-ын төв штаб мэддэг тул ямар ч ажилтан өөр ажилтны мессежийг тайлж чадахгүй. (а) "Би байрлалдаа орсон" мессеж ямар тоон утга руу шифрлэгдэхийг тодорхойл. (б) ТТГ-ын төв штаб нэгэн ажилтнаасаа \(3\) гэсэн нууцлагдсан утга хүлээн авсан гэе. Илгээсэн мессежийг тодорхойлохын тулд энэ утгын нууцлалыг тайл.

  60. \(9^{5432} \bmod{11}\)-ийг тооцоол.

61-ээс 63 хүртэлх дасгалуудад харгалзах \(n\)-ийн хувьд өгөгдсөн олонлогийг \(0 \le b \le n - 1\) байх \([b]_n\) хэлбэрээр илэрхийл.

  1. \([7]_5\).
  2. \([8]_3 + [2]_3\).
  3. \([17]_7 - [208]_7 + [1343]_7\).
  4. \(n > 1\) байх \(a, n \in \mathbb{Z}\) байг. \([a]_n\) нь хоосон биш болохыг харуул.
